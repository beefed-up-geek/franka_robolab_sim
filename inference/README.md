# inference — 학습한 VLA 추론

**아직 구현하지 않았다.** 이 문서는 무엇을 만들 것인지에 대한 계획이다.

## 목적

`data_collection` 으로 모은 데이터로 학습한 VLA 정책을 `env` 에 붙여 돌린다.

## 붙는 방식

`data_collection` 과 같은 ROS 인터페이스를 쓰되 방향이 반대다.

| 방향 | 내용 |
|---|---|
| 구독 | 카메라 이미지, 그리퍼 자세, 물체 자세 |
| 발행 | 그리퍼 자세 명령, 그리퍼 개폐 명령 |

즉 사람이 브라우저에서 하던 조작을 정책이 대신한다. 환경 쪽은 명령이 어디서
오는지 구분하지 않으므로, 사람과 정책을 바꿔 끼울 수 있다.

## 참고

RoboLab 은 정책을 **서버-클라이언트**로 돌리는 구조를 이미 갖고 있다
(`policies/pi0_family/`). 정책을 별도 프로세스로 띄우고 환경이 붙는 방식이라,
무거운 모델을 시뮬레이터와 분리할 수 있다. 그 구조를 따를지 검토할 것.

## 아직 정하지 않은 것

- 어떤 VLA 를 쓸지 (pi0 계열 / OpenVLA / 자체 학습)
- 추론 주기와 액션 청크 길이
- 실패 시 안전 정지 조건 (env 의 안전박스 클램프는 그대로 적용된다)
