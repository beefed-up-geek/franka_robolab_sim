# data_collection — 시연 데이터 수집

**아직 구현하지 않았다.** 이 문서는 무엇을 만들 것인지에 대한 계획이다.

## 목적

`env` 에서 사람이 텔레오퍼레이션으로 시연한 것을 기록해 **LeRobot 형식**으로 저장한다.
VLA 학습에 그대로 쓸 수 있는 데이터셋을 만드는 것이 목표다.

## 붙는 방식

`env` 가 띄울 ROS 노드를 구독한다 (env/README.md 의 "아직 없는 것" 참고).

| 방향 | 내용 |
|---|---|
| 구독 | 물체 자세, 그리퍼 자세, 그리퍼 개폐 상태, 카메라 이미지 |
| 기록 | 위 항목 + 조작자가 넣은 액션을 에피소드 단위로 |

시뮬레이터를 직접 import 하지 않고 ROS 를 통해서만 붙는다. 그래야 수집 코드가
실물 로봇에서도 같은 방식으로 돈다.

## 저장 형식

LeRobot 데이터셋 규약을 따른다 — 에피소드별 프레임, 관측(이미지·상태), 액션,
그리고 태스크 지시문. RoboLab 에 `scripts/convert_to_lerobot.py` 가 있으니
형식 참고용으로 먼저 볼 것.

## 아직 정하지 않은 것

- 기록 주기 (환경 제어율이 약 11Hz — 그대로 갈지 리샘플링할지)
- 카메라 구성 (현재 뷰포트 1대. 손목 카메라를 추가할지)
- 에피소드 경계 (성공 판정을 쓸지, 조작자가 수동으로 끊을지)
